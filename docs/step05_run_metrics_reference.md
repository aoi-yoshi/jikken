| `apply_global_params_sec` | サーバーから受け取った**グローバル重みをモデルに書き込む**時間 | ラウンド開始直後 |
| `post_redistribution_eval_sec` | 重み書き込み直後、**まだ学習していない**状態での accuracy 計測時間 | 上の直後 |
| `fit_duration_sec` | **ローカル学習**（local_epochs × train サンプル）の合計時間 | 学習ループ全体 |
| `local_adaptation_eval_sec` | 学習後、**client LoRA + 更新済み classifier** での eval 時間 | fit 直後 |
| `foundation_generalization_eval_sec` | **凍結した surrogate（基盤）LoRA** での eval 時間 | 上の直後 |
| `weight_divergence_sec` | クライアントと基盤の**重みベクトル差分**を計算する時間 | ほぼ一瞬 |
| `round_duration_sec` | クライアントの `fit()` 1 回の**壁時計時間**（開始〜終了） | ラウンド全体 |
| `round_overhead_sec` | 上記フェーズ合計と `round_duration` の差（Flower 内部処理など） | 自動計算 |

関連（同じ `fl_round_metrics` 行）:

| 変数名 | 意味 |
|--------|------|
| `train_time_sec` / `elapsed_sec` | fit 区間の経過時間（≈ `fit_duration_sec`） |
| `steps` | fit 中の train step 数（今回 100） |
| `avg_step_time_sec` | `fit_duration_sec ÷ steps`（1 step あたり平均秒） |
| `avg_train_loss` | 全 step の loss 合計 ÷ step 数 |

## 5. 変数辞典 — Link1（PyTorch CUDA semantics）

パス: `professor_links.link1_pytorch_cuda_semantics`

| 変数名 | 意味 | 教授向けの言い方 |
|--------|------|------------------|
| `memory_allocated_gb` | **今この瞬間**、PyTorch テンソルが実際に使っている VRAM | 現在の割当量 |
| `max_memory_allocated_gb` | 直前の `reset_peak` 以降の**ピーク**割当量 | **最大 GPU メモリ（PyTorch 視点）** |
| `memory_reserved_gb` | PyTorch が**キャッシュ用に確保**した VRAM（テンソル解放後もプールに残る） | キャッシュ込みの確保量 |
| `max_memory_reserved_gb` | reserved のピーク | reserved の最大 |
| `total_memory_gb` | GPU の物理 VRAM 総容量 | 8 GB クラス |
| `device_name` | GPU 名 | RTX 5050 など |
| `cuda_capability` | GPU アーキテクチャ版 | `12.0` = Blackwell 系 |
| `multi_processor_count` | GPU 内の SM（演算ユニット）数 | 20 |

**覚え方:** `allocated` ≤ `max_allocated` ≤ `reserved`（だいたい）。教授が言う「最大メモリ」は **`max_memory_allocated_gb`** を報告するのが基本。

トップレベル（`fl_round_metrics` 直下）の `memory_allocated_gb` 等は、Link1 と**同じタイミング・同じ値**のコピー。

## 6. 変数辞典 — Link3（nvidia-smi）

### 6.1 スナップショット `link3_nvidia_smi_snapshot`

**1 瞬間**のドライバ視点。fit **終了直後**に 1 回取得。

| 変数名 | 意味 |
|--------|------|
| `smi_utilization_gpu_percent` | GPU コアの使用率 [%]（その瞬間） |
| `smi_utilization_memory_percent` | メモリバスの使用率 [%] |
| `smi_memory_used_gb` | **全プロセス合計**の VRAM 使用量（Chrome 等も含む） |
| `smi_memory_free_gb` | 空き VRAM |
| `smi_memory_total_gb` | 総 VRAM |
| `smi_power_draw_w` | 消費電力 [W] |
| `smi_temperature_gpu_c` | GPU 温度 [°C] |
| `smi_clocks_current_sm_mhz` | 現在の SM クロック |
| `smi_clocks_max_sm_mhz` | 最大 SM クロック |
| `driver_version` | NVIDIA ドライバ版 |

**Link1 との違い:** `smi_memory_used_gb` は **Windows 上の全アプリ合計**。PyTorch だけの `memory_allocated` とは一致しないことがある（今回はほぼ一致）。

### 6.2 学習中要約 `link3_nvidia_smi_timeseries`

fit 中に **毎 train step** サンプルした結果の **min / max / avg / n** のみ保存（生の 100 点は保存しない）。

| 変数名 | 意味 |
|--------|------|
| `gpu_util_percent.min/max/avg` | 学習中の GPU 使用率の最小・最大・平均 |
| `memory_util_percent.min/max/avg` | メモリバス使用率の要約 |
| `nvidia_smi_used_memory_gb.min/max/avg` | used VRAM の要約 |
| `n` | サンプル数（今回 100 = 100 step） |

トップレベル `nvidia_smi_timeseries` は中身同じ（重複コピー）。
