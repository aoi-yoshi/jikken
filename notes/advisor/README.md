# notes/advisor — Cursor 向け研究コンテキスト（ローカル専用）

**GitHub には同期されません**（`.gitignore` で `context.md` を除外）。

## 目的

このフォルダは **Cursor が吉村さんの意図と先生の方針を読み取るため** の場所です。  
実験コード（`docs/`）や run ログ（`artifacts/`）とは別に、「何を優先するか」「報告で何を求められているか」をここに集約します。

## 使い方

1. Slack などの会話をチャットに貼る
2. 「`context.md` に追記して」と依頼する
3. Cursor が **`context.md` 1 ファイル** を更新する（方針・アクション・会話ログ）

**日付ごとにファイルを増やさない。** 分割すると Cursor が古いファイルを読まず、方針が欠落しやすい。

## ファイル

| ファイル | 役割 |
|---------|------|
| `context.md` | 唯一の本体（方針・アクション・会話ログ）— **ローカルのみ** |
| `README.md` | この説明 — GitHub に載る |

## docs/ との違い

- **`notes/advisor/context.md`** … Cursor 用の生コンテキスト（先生の言葉、優先順位、未送信の返信下書き）
- **`docs/`** … リポジトリに載せる整理済み資料（例: `progress_meeting_*.md`）
